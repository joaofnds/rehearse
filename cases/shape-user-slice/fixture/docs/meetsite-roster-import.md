# The meet site's Import Roster

Read from the meet site's coach help pages and its Import Roster panel, 2026-09-11.
Not tried against a coach account.

- The coach uploads an Excel or CSV file on the Import Roster screen, which offers an
  Excel template and a CSV template.
- Columns: Last Name, First Name, HS Grad Year, Gender (`M` or `F`), and optionally
  Birthday (`MM/DD/YYYY`). The panel marks only Birthday as optional.
- HS Grad Year is always the year the athlete finishes high school, including for
  middle-school athletes. The meet site derives grade and age groups from it.
- The template has no meet-site id column, so an imported row cannot point at an
  athlete the meet site already has. The help pages ask coaches to check for an
  existing athlete before adding one.
- An athlete cannot be deleted from a meet-site roster once imported. The coach can
  only deactivate them.
- Importing a roster enters nobody in a meet. Meet entries are a separate upload.
